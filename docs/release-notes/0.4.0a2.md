This experimental alpha fixes an update blocker and reduces the Windows companion download size. Python and the Windows companion share version `0.4.0a2` and the same source revision.

## Fixed

- Historical failed scheduled-investigation launch receipts no longer prevent an update when no active or uncertain work remains. History is preserved, and active-work and recovery checks still apply.
- Update instructions explicitly select a supported Python interpreter instead of accidentally using an older system Python.

## Smaller Windows download

The Windows companion is now distributed as `.7z`, with the same runtime files and per-file integrity manifest. Windows 11 24H2 or newer can extract it through File Explorer; older Windows versions need [7-Zip](https://www.7-zip.org/) or another compatible extractor. This changes download compression, not installed size.

## Install or update

This alpha is distributed through GitHub Releases, not PyPI. Verify the selected assets against `SHA256SUMS` before use. The Python wheel and Windows companion are separate downloads; the companion remains required for WSL background supervision even when its window is hidden.

For an existing WSL/uv installation, follow the [coordinated update procedure](https://github.com/Alek2077/dependabot-watcher/blob/v0.4.0a2/docs/setup.md#coordinated-wsluv-update-development) from a clean checkout of `v0.4.0a2`, with the matching extracted companion. Preserve the current installer, supported interpreter, settings, history and scheduler. Do not overwrite a running component or edit old receipts to force an update. Other installation paths should follow the [installation and lifecycle guidance](https://github.com/Alek2077/dependabot-watcher/blob/v0.4.0a2/docs/setup.md).

## Validation and limitations

Local package and Windows extraction checks passed. Hosted CI is temporarily suspended; this release does not claim hosted validation. The Windows companion is unsigned. A complete installed coordinated update remains a separate acceptance check. See the [validation record](https://github.com/Alek2077/dependabot-watcher/blob/v0.4.0a2/docs/validation.md).

This remains an experimental release, with the existing workflow and platform limitations.
