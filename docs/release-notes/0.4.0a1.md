# 0.4.0a1 — experimental alpha

This is an experimental prerelease, not a stable or unattended-maintenance release. Python and the Windows companion share this version and source revision.

## Added and improved

- Repository-workflow assessment using current trusted instructions and explicit selected-checkout scope. Unsupported integration methods receive a handoff rather than an assumed fast-forward.
- Coordinated WSL/uv backend and Windows updates, verified graceful window shutdown, scheduler-definition preservation and interrupted-update recovery.
- Clearer review-window grouping, current checkout comparisons, separate historical receipts, batch command approvals and guarded PR branch-update continuation.
- Structured supervisor prompts and real-provider context-handoff acceptance tests.
- Version-specific release notes and a GitHub prerelease channel independent of PyPI publication.

## Updating

Use the [documented update procedure](../setup.md#coordinated-wsluv-update-development) and the matching Windows archive when that component is installed. Existing settings, history and scheduler identity should be preserved. Review active work before updating; do not force-kill an approved operation. The Python CLI version must match the selected companion's release manifest. Basic CLI operation does not require the Windows archive; the currently supported WSL scheduled-supervisor route does.

## Known limitations

Only separately approved clean fast-forward local integration is executable. Other repository methods remain explicit unsupported handoffs. Exact tool-phase/output telemetry, detailed usage accounting and in-app preference editing remain future work. Elapsed wall time is not proof of tool progress.

Local Python/native and installed-artifact checks exist, including real-provider context exercises with synthetic GitHub transports. Hosted release execution and a full installed coordinated update still require acceptance; do not infer these from local tests. The Windows archive is unsigned. Prereleases are distributed through GitHub and are not automatically uploaded to PyPI.
