# Security policy

## Supported versions

Before the first published release, the source is experimental and there is no supported versioned security release. Reports about current development source are welcome. After publication, security fixes target the latest published release; older releases and development snapshots are not maintained as separate security branches. An alpha label does not imply that a security audit has been completed.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Alek2077/dependabot-watcher/security/advisories/new) instead of opening a public issue. Include the affected version, impact, reproduction steps, and any suggested mitigation when available.

The maintainer must enable and verify this reporting channel when making the repository public. If the private reporting form is unavailable, do not disclose vulnerability details in a public issue; an ordinary issue may request a private contact route without including sensitive details.

Reports are reviewed on a best-effort basis. The project does not promise a specific response or resolution time. Please avoid public disclosure until the maintainer has had a reasonable opportunity to investigate and prepare a fix.

For ordinary bugs and feature requests that do not expose a security weakness, use [GitHub Issues](https://github.com/Alek2077/dependabot-watcher/issues).
