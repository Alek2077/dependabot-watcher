# Security policy

## Supported versions

Before the first published release, the public source is prerelease software and
there is no versioned security release. After publication, security fixes are
provided for the latest published `0.3.x` release; older development snapshots
and unreleased source revisions are not supported security releases.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/Alek2077/dependabot-watcher/security/advisories/new)
instead of opening a public issue. Include the affected version, impact,
reproduction steps, and any suggested mitigation when available.

Reports are reviewed on a best-effort basis. The project does not promise a
specific response or resolution time. Please avoid public disclosure until the
maintainer has had a reasonable opportunity to investigate and prepare a fix.

For ordinary bugs and feature requests that do not expose a security weakness,
use [GitHub Issues](https://github.com/Alek2077/dependabot-watcher/issues).
